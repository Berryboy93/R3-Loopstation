# R3 NATIVE Complete UI Build Specification & Replit Prompt

> This document is the authoritative specification for building the R3
> NATIVE browser-based DAW.

## Objective

Build a premium browser DAW with the approved Aurora design language.

### Core UI

-   Midnight Black foundation (#080808)
-   Neon Native Green (#B7FF00)
-   Titanium Silver accents
-   Graphite surfaces
-   Glassmorphism, modular dockable panels
-   Hardware-inspired knobs, faders, LED meters
-   Responsive desktop-first layout

### Required Workspaces

-   Dashboard
-   Studio Home
-   Multi-track Arrangement
-   Mixer
-   Piano Roll
-   Drum Machine
-   Sampler
-   Loop Station
-   Plugin Browser
-   AI Studio
-   Vocal Production
-   Marketplace
-   Collaboration
-   Settings

### Vocal Production

Integrate professional pitch-correction capability with: - Realtime
pitch correction - Graphical/manual editing - Key, Scale, Retune Speed,
Humanize, Formant, Mix controls - Low-latency monitoring - Pitch graph -
Automation support Use appropriately licensed technology where required.

### Design System

Define reusable tokens for colors, typography, spacing, radii,
elevation, shadows, borders, motion and component states.

### Engineering

Frontend: - React + TypeScript + Vite - Tailwind CSS - Component-driven
architecture Backend: - Node.js - PostgreSQL - API-first services
Support offline-first workflows, autosave, collaboration, accessibility,
testing, performance budgets and security.

## Replit Prompt

You are building the complete production-ready R3 NATIVE DAW. Implement
the application strictly according to this specification. Preserve the
Aurora visual language, modular architecture, reusable component
library, accessibility, responsive behavior, AI-assisted workflows, and
integrated vocal production tools. Produce maintainable, typed,
documented code. Avoid placeholder implementations where
production-ready solutions are feasible. Keep branding and presentation
consistent across every screen.
